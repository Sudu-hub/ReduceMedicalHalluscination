# Evaluation

## Subfolders
- `metrics/` — implementations of evaluation metrics
  - `answer_accuracy.py`
  - `hallucination_rate.py`
  - `expert_alignment.py`
  - `overall_reliability.py`
- `benchmarks/` — loaders for the medical QA benchmarks
  - `pubmedqa/` — PubMedQA dataset adapter
  - `truthfulqa/` — TruthfulQA dataset adapter
  - `medhallu/` — MedHallu dataset adapter
  - `medhallbench/` — MedHallBench dataset adapter
